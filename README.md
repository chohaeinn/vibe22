# INCLUSE — AI 기반 행사 자동 설계 플랫폼

보고서의 주요 기능을 바탕으로 만든 Streamlit 프로토타입입니다.

## 실행 방법
1. GitHub 저장소에 `app.py`, `requirements.txt`, `README.md`를 업로드합니다.
2. Streamlit Community Cloud에서 저장소를 연결합니다.
3. Main file path를 `app.py`로 지정하고 Deploy합니다.

로컬 실행:
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 구현된 기능
- 행사명·장소·유형·목표·방문객·예산·시간·부스 정보 입력
- 행사장 형태 선택 및 배치도 시각화
- 혼잡도 Heatmap 형태의 참고 시각화
- 안전성·혼잡도 관리·접근성·운영 효율성·참여성·예산 효율성 점수와 산정 근거
- 부스 위치/크기 편집
- 방문객 급증·우천·공연 지연·출입구 혼잡·응급환자 발생 시나리오
- 이용자 유형별 접근성 점검
- 배치 CSV, 결과 JSON, PDF 리포트 다운로드

## 중요한 구현 범위
이 코드는 외부 LLM, 학습된 AI 모델, 실제 군중 시뮬레이터, 데이터베이스, React/Three.js 디지털 트윈 서버를 연결하지 않은 실행 가능한 프로토타입입니다. 보고서에 적힌 수천 개 시나리오 최적화나 실시간 분석을 실제로 수행한다고 주장하지 않으며, 규칙 기반 예시 점수와 시각화를 제공합니다. 실제 안전 계획에는 현장 도면, 수용 인원 산정, 관련 법령과 전문가 검토가 필요합니다.
